# Culicitree Github

This repository will store various scripts, data files, and output for manuscripts involved in the Culicitree project (https://culicitree.org/)

Scripts from Soghigian et al. 2023 can be found within that folder; See scripts in comphet/Soghigian et al. 2026 for scripts relevant to that recent paper.
